# lab-site
研究室のWebサイト

[公開サイト](https://hhlab.github.io/lab-site/)

いつでも変更してください！

ヘッダーの「日本語 / English」でサイト全体の表示言語を切り替えられます。
初期表示は日本語です。選んだ言語はブラウザに保存され、次回の訪問にも適用されます。
保存が制限されているブラウザでも、そのページ内での切り替えは利用できます。

本文は `data/content.js`、メンバー情報は `data/members.js` で編集します。
日本語の項目と対応する英語の項目（`titleEn`、`textEn`、`gradeEn`、`interestsEn` など）を一緒に更新してください。
メンバーの英語氏名は `en`、ナビゲーションなどの短い文言は `js/i18n.js` にあります。
